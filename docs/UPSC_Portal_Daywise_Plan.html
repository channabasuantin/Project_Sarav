UPSC Notes Portal — Day-by-Day Build Plan

Subject-wise notes & question papers · Admin upload · Student view/download · Cloudflare + Supabase + R2
Assumption: ~2–3 hours per day (21 working days). Double daily hours to finish in ~10–11 days.

Goal: Replace WhatsApp/Telegram PDF hunting with one link — subject tiles (Polity, History, …), day/topic filters, in-browser PDF view, download. Only you upload; 1000+ students read via CDN (handles 10,000+ visitors). PDF storage: 10 GB free on R2, then ~₹1.25/GB/month (50 GB cap in ops).

Week 1 — Accounts, backend, storage

DayFocusTasks (checklist)Done when
Day 1 Accounts & repo
  • Create GitHub account/repo (private) for code only
  • Sign up: Cloudflare, Supabase (free tier)
  • Install Node.js LTS, Git, VS Code/Cursor
  • Clone/init project folder; add .gitignore (.env, node_modules)
 Empty repo pushed; three cloud accounts ready
Day 2 Supabase database
  • Create Supabase project (region closest to India if available)
  • Tables: subjects, materials (day, topic, title, type, file key, size, published)
  • Seed subject rows: Polity, History, Geography, Economy, etc.
  • Enable Row Level Security: public read if published; no public write
 Subjects visible in Supabase table editor; RLS on
Day 3 Admin auth
  • Supabase Auth: email + strong password (your admin only)
  • RLS policies: INSERT/UPDATE/DELETE only for your user UUID
  • Document URL + anon key in local .env (never commit secrets)
 You can log in via Supabase Auth test; policies block anon writes
Day 4 Cloudflare R2
  • Create R2 bucket (e.g. upsc-materials)
  • Enable public access via custom domain or r2.dev subdomain for PDF URLs
  • Create API token (R2 read/write); store in Supabase secrets for later
  • Set CORS: allow your site origin + PUT for uploads
 Test file uploadable in R2 dashboard; URL opens in browser
Day 5 Upload API (Edge Function)
  • Function init_upload: verify JWT → return presigned PUT URL + material id
  • Function complete_upload: verify file exists → set published = true
  • Test with curl or Postman using admin token
 One PDF uploads end-to-end without using the website UI yet
Day 6 Frontend scaffold
  • Create Astro + Tailwind app under apps/web
  • Env: Supabase URL, anon key, public R2 base URL
  • Layout: mobile-first header, footer, institute name
 npm run dev shows home page locally
Day 7 Subject tiles (student)
  • Home page: grid of subject tiles from Supabase
  • Each tile links to /subject/[slug]
  • Basic styling: large tap targets for phones
 All subjects clickable; list page loads (can be empty)
